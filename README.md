# Fantasy Breach

*Step through. Reality is yours for the making.*

A long-form AI text adventure that becomes a visual novel as you play: a
narrator that remembers your story, characters with portraits and outfits,
painted places, music and ambient sound.

**Download:** see [Releases](../../releases) and get the latest
`FantasyBreach-Setup-<date>.exe`.

## Installing

- Windows 10 or 11, 64-bit. Nothing else to install first.
- Run the setup file. It installs for your account only (no administrator
  rights) and can add a desktop shortcut.
- Windows may say **"Windows protected your PC"** because the installer isn't
  signed. Click **More info**, then **Run anyway**.
- Uninstall any time from **Settings → Apps**. Your saves stay in
  `Documents\My Games\FantasyBreach` either way.

## What you need

- An **OpenRouter** API key with some credit (https://openrouter.ai/keys).
  The story is written by the AI models you pick there, and you pay
  OpenRouter for what you use: from a fraction of a cent to a few cents a
  turn, depending on the model.
- Optional: a **Runware** key (cheaper images that allow adult content) and an
  **ElevenLabs** key (ambient sound).
- Enter your keys in **⚙️ Settings** inside the app. They're stored in Windows
  Credential Manager on your PC and never leave it except to go to the
  provider they belong to.

The first time memory search runs, it downloads a small model (about 65 MB).
